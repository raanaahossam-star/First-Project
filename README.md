# 📊 Design & Sales Dashboard | Power BI Project

## 📌 Project Overview
This Power BI project provides interactive dashboards for analyzing project performance, client insights, and sales activities.  
The dashboards help monitor KPIs, track client status, evaluate sales performance, and support data-driven business decisions through dynamic visualizations.
